# Blackjack 3:2 · Normal Penetration

Static GitHub Pages blackjack game.

## Rules

- 6 deck regular shoe, not a continuous shuffle machine
- Visible shoe progress and discard tray
- Blackjack payout: 3:2
- Penetration: 78%
- Dealer hits soft 17
- Splits allowed on duplicate ranks
- Equal bet on split hands, except Aces are restricted
- Insurance is offered when dealer shows an Ace
- 4 to 6 computer players with sub par, average, and good skill levels
